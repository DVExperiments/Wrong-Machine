01 / IMAGE INPUT
PIXEL FIELD AWAITING INPUT
ADVANCED / PIXEL BYTE EDITOR +

Modify a small block of raw RGBA pixel bytes in hexadecimal. This safely edits decoded pixels, not fragile PNG/JPEG headers.

TIP: Every pixel has 4 bytes: red, green, blue, alpha. Preserve alpha (FF) for opaque pixels. Avoid editing thousands of bytes at once. Download the resulting PNG to preserve a valid image.

WHAT ARE YOU HEARING?

True spectral painting reads decoded pixels as frequency magnitudes. Phase is not present in an image and must be reconstructed; no synth bed is added. Raw file mode instead reads the actual uploaded bytes as PCM.

THREE WAYS TO SEE A SONG

Spectrogram maps frequency energy over time; sample pixels map waveform values to colours; wave spiral creates an artistic polar trace. They reveal different aspects of the same audio.
